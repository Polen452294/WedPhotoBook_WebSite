# Мобильная производительность

Главная страница оптимизирована под Lighthouse/PageSpeed без изменения её текста и макета.

## Критический путь

- LCP-фото имеет AVIF/WebP `srcset`, точный `sizes`, `fetchpriority="high"` и HTTP `Link` preload.
- Геометрия фото заранее зарезервирована через `width`/`height`, что сдерживает CLS.
- CSS первого экрана встраивается сборщиком; оптимизированные стили главной подключаются напрямую.
- Open Sans хранится локально в variable WOFF2 с `font-display: swap`.
- Логотип и социальные иконки загружаются как готовые статические файлы без image proxy.

## Ниже первого экрана

- Фото и карусели используют lazy loading; в начальном HTML есть только активный кадр.
- Клиентский скрипт главной реализует только меню, форму, cookies и карусели.
- Тяжёлые универсальные transition-правила удалены; сохранены только точечные анимации.
- На ширинах 320, 390 и 412 px сетка и длинные слова не создают горизонтальную прокрутку.

## Проверка

```bash
npm run lint
npm run build
npm test
npm run check:assets -- --base-url=http://127.0.0.1:3000
```

После публикации нужно повторить PageSpeed для production URL: балл зависит от текущей нагрузки VPS, сети Google и
версии Lighthouse. Важны фактические FCP, LCP, TBT, CLS и список новых диагностик, а не один случайный балл.
