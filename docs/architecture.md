# Архитектура

- Интерфейс и серверные маршруты: Next.js App Router поверх Vinext.
- Production runtime: Cloudflare Workers/Sites.
- Хранилище: Cloudflare D1 через Drizzle ORM; миграции находятся в `drizzle/`.
- Идентификация администратора: Sign in with ChatGPT, затем серверная проверка точного email по `ADMIN_EMAILS`.
- Публичные страницы читают разрешённые изменения текста из D1. Панель изменяет только известные маршруты и допустимые DOM-ключи.
- Аналитика first-party записывается в D1 только после согласия посетителя.
- Административные изменения защищены same-origin-проверкой, ограничением частоты, оптимистической блокировкой и журналом аудита с хешами значений.

Публичный сайт остаётся доступным без входа. `/admin/` и изменяющие состояние административные API всегда требуют серверной авторизации; клиентский интерфейс не является границей безопасности.
