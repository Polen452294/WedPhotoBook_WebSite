# Архитектура

- Интерфейс и API: Next.js App Router в Node.js runtime.
- Production: один процесс Next.js за nginx на VPS.
- Хранилище: локальный SQLite вне каталога релиза; доступ через Drizzle ORM.
- Схема и миграции: `db/schema.ts` и `drizzle/`; миграции выполняются до запуска приложения.
- Админ-панель: собственная страница входа с одним паролем, подписанная `Secure`/`HttpOnly`
  cookie, same-origin-проверки, rate limit, оптимистическая блокировка и журнал аудита.
- Заявки: атомарная запись в SQLite, затем аутентифицированный HTTP-вызов только на `127.0.0.1`,
  локальная очередь Postfix и DKIM-подпись.
- Аналитика: first-party события пишутся только после согласия посетителя.
- Медиа: заранее подготовленные AVIF/WebP-варианты и `srcset`; в runtime обработка изображений не нужна.

Публичный сайт остаётся доступен без входа. `/admin/` и изменяющие состояние API всегда требуют серверной
авторизации; клиентский интерфейс не является границей безопасности.
