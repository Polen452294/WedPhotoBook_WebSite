# Качество фотографий

`SiteImage` сохраняет стандартное поведение `next/image` для иконок. Фотографии
загружаются непосредственно из лучшего доступного исходника без повторного сжатия
или уменьшения на image endpoint. Размеры в макете и отложенная загрузка сохранены.
Та же политика действует для фотографий в захваченных WordPress-страницах.

`data/photo-sources.json` связывает уменьшенные копии с подтверждёнными исходниками
того же изображения. Включены 15 кадров галереи шириной 2000 пикселей, полные
скриншоты отзывов и оригинальные JPEG с исходного сайта. Происхождение скачанных
файлов и их размеры записаны в `public/media/originals/manifest.json`.
Исходные файлы не перерисовывались и не пересохранялись.

Главный снимок загружается в разрешении 1767×1255, фотографии тарифов «Премиум»
и «Стандарт» — 900×600 вместо 450×300. Часть обложек остаётся 500×500: большего
исходника той же композиции не найдено. Изображения нельзя сделать детальнее
простым увеличением числа пикселей; для дальнейшего улучшения нужны исходники.

Полные файлы увеличивают объём загрузки по сравнению с миниатюрами. Не возвращайте
для крупных фотографий пути из `media/optimized/home` и `media/optimized/covers`
без проверки чёткости. При замене содержимого обновляйте версию фото в
`lib/media-path.ts`, чтобы браузер не показывал закешированную копию.

Проверка: `npm run lint`, `npm run build`, `node --test tests/rendered-html.test.mjs`
и `npm run check:assets`.
